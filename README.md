# 绒卡蒂 · RongKadi

一个住在 QQ 里的 AI 陪伴机器人。

她有自己的 QQ 号、自己的人设文件、自己的记忆，还会自己发 QQ 空间。
这个仓库是她的公开门面 + 一点工程笔记 —— **完整源码不在这里**（里面有我自己的 API 密钥和私有设定）。

---

## 她是什么

- **有人设**：一份人设文件定义她怎么说话、什么能说什么不能说、对不同的亲密度分别是什么态度（4 档，从"客气"到"黏人"）。
- **有记忆**：跨会话记住聊过的人和事；"看过的作品"会自己写回人设，所以下次聊到能接得上。
- **有生活**：每 30 分钟自己发一条 QQ 空间；也会按时间自己找人说句话，不是只被动回复。
- **有边界**：被要求自我暴露、越界、或者有人想套她的提示词，会被规则闸门拦下来。
- **有钱包**：余额见底她就停机 —— 所有聊天（私聊 / 群聊 / 主动开口）都先查余额。

## 大概是怎么跑起来的

```
QQ ──(NapCat)──> OneBot v11 ──> 本地桥 (Node.js)
                                   │
                                   ├─ 1. 消息合并 / 去重 / 排队
                                   ├─ 2. 拼提示词：人设 + 记忆 + 当前场景
                                   ├─ 3. 调模型（headless 子进程，JSON 事件流）
                                   ├─ 4. 出话前过一遍规则闸门（纯函数，带单测）
                                   ├─ 5. 记账：这一轮烧了多少，从余额里扣
                                   └─ 6. 发回 QQ
```

几个我自己比较满意的细节：

- **规则不靠"在提示词里求模型听话"**，而是做成纯函数闸门 + 单元测试。
  提示词会被绕过，代码不会。每条闸门都拿真实翻车记录当测试用例。
- **记账只认她自己那一份用量**：桥把每轮调用的 token 计数写进日志，
  另一个脚本按字节偏移量往后读增量 —— 谁花的钱算谁的，不会把别的会话的开销算到她头上。
- **看过的作品**：她聊完一个作品，代码把标题写进人设文件里的一个受控区块，下次提示词就带上了。
  那个区块由代码维护，手改会被覆盖（踩过坑）。
- **主动说话**：定时器 + 冷却 + 上限，避免她半夜刷屏或者跟另一个机器人互相刷无限对话。
